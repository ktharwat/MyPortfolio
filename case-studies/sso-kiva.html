US remote · 2010–2013 · Software Engineer

Enterprise SSO at Kiva Group.

One identity across the company's systems — built fully remotely with a US team, years before remote work was normal.

Context

Kiva Group, a US company running multiple systems and properties, hired me as a fully remote software engineer based in Egypt. Every system had its own login, its own user store, its own password rules.

Challenge

Identity fragmentation taxed everyone: users juggled credentials across properties, support burned hours on resets, and every new system added another account silo to maintain.

Constraints

  • 2010-era tooling — no mature managed identity vendors to lean on
  • Fully remote collaboration across continents, before it was common practice
  • Early-career resources: correctness had to come from design discipline, not headcount

My role

Engineer owning the SSO build end to end, plus the database layer beneath it — schema design and stored procedures where integrity mattered most.

Decisions

Centralize identity in one service before federation was fashionable.

One authoritative store, one session authority. Every property integrated against it instead of holding its own copy of the truth.

Stored procedures at the integrity boundary.

Credential operations went through controlled database logic rather than ad-hoc queries. Security-critical paths got exactly one implementation each.

Design for new systems joining cheaply.

The measure of an SSO system isn't the first integration — it's how little the tenth one costs. Integration was designed as configuration, not as surgery.

Execution

Built the central authentication service, designed the underlying schemas, wrote the stored procedures for credential lifecycle operations, and integrated the existing properties — coordinating all of it asynchronously with a distributed team.

Results

1
identity per user across the company's systems
1
authoritative credential store instead of one per property
100%
remote delivery — three years of cross-continent collaboration

Business impact

Account management consolidated into one place, support stopped paying the reset tax repeatedly, and onboarding a new property meant integrating — not rebuilding — authentication.

Lessons

Identity done once, correctly, pays dividends for a decade. And the remote-working discipline I learned in 2010 — write things down, over-communicate status, trust output over presence — still shapes how I lead distributed teams today.
