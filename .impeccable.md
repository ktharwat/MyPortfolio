# Design Context for KeroProfile

## Positioning
Kyrellos Tharwat is positioned as **"the keeper of critical systems"**: an engineering lead who modernizes business-critical software without stopping the business. 12+ years, pharma (Eva Pharma) to US remote teams, currently leading 9 engineers. The portfolio targets engineering leaders, CTOs and recruiters first; selective consulting clients second.

### Brand Personality
Senior, calm, evidence-driven. Claims are always scoped (metric + baseline + timeframe). No hype language, no emoji iconography, no unverifiable percentage walls.

## Aesthetic Direction — "Ink & Copper"
- Warm paper background (#FAF9F6), ink text (#101820), ONE copper accent (#B4633A), hairline borders (#E3DFD7).
- Dark mode is a true token inversion, not a `--white` override hack.
- Mono metadata (JetBrains Mono) for kickers, dates, metrics.
- Zero infinite animations. One subtle fade-rise reveal on scroll (JS-gated via `html.js .reveal`), honoring `prefers-reduced-motion`.

### Typography
- English display: Sora · English body: Inter
- Arabic (display + body): IBM Plex Sans Arabic (`html[lang="ar"]` swaps tokens automatically)
- Metadata/metrics: JetBrains Mono

### Design Principles
1. **Evidence before adjectives**: every claim carries scope; case studies are the proof layer.
2. **Bilingual by authorship**: Arabic content is written natively (MSA, own rhetoric order), not machine-mirrored from English. Tech terms stay Latin inside RTL with bidi isolation.
3. **Logical CSS properties everywhere** (`margin-inline`, `border-inline-start`) so RTL needs no `[dir="rtl"]` patch rules.
4. **No dead ends**: every page ends in a contact band; footer links exist for real.

## Technical Guidelines
- Static HTML/CSS/JS only. Shared assets: `assets/css/style.css`, `assets/js/i18n.js`.
- Each page defines `window.I18N = { en: {...}, ar: {...} }` (keys = `data-i18n` attributes; `__title` swaps `document.title`). `i18n.js` handles persistence (`localStorage: kt-lang`), first-visit detection via `navigator.language`, RTL/LTR flip, and the reveal observer.
- An inline head script sets `<html lang/dir>` before paint to avoid FOUC.
- Résumé single source: `resume.html` mirrors `Kyrellos_Tharwat_Resume.pdf` (exact filename — never link a `_v3`-style file that doesn't exist). Print stylesheet hides nav/footer.
- Keep pages lean: no frameworks, one shared stylesheet, Google Fonts with limited weights.
